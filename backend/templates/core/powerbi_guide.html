Manual de Instrucciones: Power BI (.pbix)

Este es el manual completo paso a paso que te guiará desde cero para descargar Power BI, conectarlo a nuestra arquitectura de datos en Docker y construir el archivo .pbix exigido en tu taller de Business Intelligence de RetailStart.

0. Descargar e Instalar Power BI Desktop

Power BI Desktop es la herramienta gratuita de Microsoft donde se construyen los reportes. Para obtenerla:

  1. Opción recomendada (Microsoft Store): Si usas Windows 10 u 11, abre la aplicación "Microsoft Store", busca Power BI Desktop y dale a Instalar. Esta versión se actualiza automáticamente.
  2. Opción alternativa (Web): Ingresa a powerbi.microsoft.com/desktop/, haz clic en "Descargar gratis" e instala el archivo .exe en tu equipo.
  3. Inicia el programa. Si te pide iniciar sesión, puedes cerrarla (la "X" de arriba a la derecha), no es estrictamente necesario tener cuenta para conectarte localmente y armar tu archivo.

1. Obtener Credenciales de Conexión

Nuestro modelo estrella está alojado dentro de tu servidor local en Docker usando PostgreSQL. Para que Power BI vea los datos, usa exactamente esta información:

  • Servidor: localhost (o 127.0.0.1)
  • Puerto: 5433 (Docker expone este puerto al exterior para no chocar con instalaciones locales)
  • Base de Datos: retailstart
  • Usuario: retailstart
  • Contraseña: retailstart

Importante: antes de conectar, verifica que Docker esté corriendo con docker compose up. Si el puerto 5433 no responde, la conexión fallará con “el equipo de destino denegó expresamente la conexión”.

2. Conectar Power BI a PostgreSQL

  1. En la pantalla de inicio de Power BI, ve a la cinta de opciones (Inicio) y selecciona Obtener datos > Más....
  2. Busca y selecciona Base de datos PostgreSQL. Haz clic en Conectar.
  3. Si te aparece un aviso sobre "Npgsql", dale a "Aceptar" o "Aceptar riesgos" (es porque estamos conectando de forma local).
  4. En la ventana emergente, ingresa el servidor (localhost:5433) y la base de datos (retailstart).
  5. En la sección Modo de conectividad de datos, selecciona Importar (te cargará los datos a la memoria RAM de Power BI, ideal para este volumen de datos). Haz clic en Aceptar.
  6. Al pedir credenciales, ingresa tu usuario (retailstart) y contraseña (retailstart) creados en el Docker. Selecciona el nivel inferior (la base de datos) para aplicar las credenciales.

3. Seleccionar las Tablas del Modelo Estrella

Al conectar, verás las tablas de la base de datos. Como usamos PostgreSQL, es probable que las tablas aparezcan con el prefijo public. Selecciona las siguientes tablas que conforman nuestro modelo:

  • public core_factventas
  • public core_dimcliente
  • public core_dimproducto
  • public core_dimtiempo
  • public core_dimcanal
  • public core_dimtienda

Haz clic en Cargar. Las tablas se importarán a Power BI.

4. Validar las Relaciones (Modelo Analítico)

El "Esquema Estrella" requiere que la tabla de hechos (ventas) esté conectada a todas las dimensiones. Ve a la vista de Modelo (el ícono con tres cuadritos conectados en la barra lateral izquierda). Power BI probablemente detecte las relaciones automáticamente, pero debes validarlas manualmente:

Si falta alguna relación, haz clic sobre el campo de ID en la tabla de dimensión y arrástralo sin soltar el clic hasta el campo correspondiente en public core_factventas. Asegúrate de que las relaciones queden así:

  • Cliente: Arrastra 'public core_dimcliente'[id] hacia 'public core_factventas'[cliente_id]
  • Producto: Arrastra 'public core_dimproducto'[id] hacia 'public core_factventas'[producto_id]
  • Tiempo: Arrastra 'public core_dimtiempo'[id_tiempo] hacia 'public core_factventas'[fecha_id]
  • Canal: Arrastra 'public core_dimcanal'[id] hacia 'public core_factventas'[canal_id]
  • Tienda: Arrastra 'public core_dimtienda'[id] hacia 'public core_factventas'[tienda_id]

Nota: Al crearse la línea, verás un 1 del lado de la dimensión y un asterisco (*) del lado de la tabla de hechos. Esto significa "1 a varios" y es la cardinalidad exacta que busca tu evaluación.

5. Crear las Medidas DAX

Las Medidas son cálculos dinámicos (como fórmulas de Excel) que Power BI calcula al vuelo. Para crear una medida:

  1. En el panel lateral derecho de "Datos", despliega la tabla public core_factventas.
  2. Haz clic derecho sobre el nombre de la tabla y selecciona Nueva medida.
  3. Aparecerá una barra de fórmulas en la parte superior. IMPORTANTE: Power BI escribirá Medida = por defecto. Borra ese texto y pega una a una las siguientes fórmulas (dale a Enter tras cada una).
Ventas Totales = SUM('public core_factventas'[monto])

Cantidad de Ventas = COUNTROWS('public core_factventas')

Venta Promedio = AVERAGE('public core_factventas'[monto])

Clientes Activos = DISTINCTCOUNT('public core_factventas'[cliente_id])

Ventas Online = CALCULATE(
    SUM('public core_factventas'[monto]),
    'public core_dimcanal'[canal] IN {"web", "app"}
)

Ventas Presenciales = CALCULATE(
    SUM('public core_factventas'[monto]),
    'public core_dimcanal'[canal] = "pos"
)

Sabrás que funcionó porque verás aparecer un pequeño ícono de calculadora junto a "Ventas Totales" y al resto de las medidas que acabas de crear dentro de tu tabla.

💡 Plan B (Opcional): Renombrar las tablas para tener fórmulas más cortas

Si no quieres que tus tablas y fórmulas tengan el prefijo public con comillas simples, puedes renombrarlas. Ve a la vista de Modelo, haz doble clic en el título de cada tabla (ej. public core_factventas), borra la palabra "public " y presiona Enter. Si haces esto, tus fórmulas DAX serán más limpias (ej. SUM(core_factventas[monto])).

6. Armar los Dashboards (Visualizaciones)

Vuelve a la Vista de Informe (el ícono superior izquierdo de gráfico de barras). Ahora recrearás la parte visual basándote en la rúbrica y nuestra aplicación web.

Para añadir cualquier gráfico, haz clic en el ícono deseado dentro del panel Visualizaciones (derecha) y luego arrastra tus campos hacia las cajas de "Eje X", "Eje Y", "Valores", etc.

  • KPIs y Resumen (Tarjetas): Selecciona el objeto visual "Tarjeta" (el ícono con un 123). Luego, arrastra tu medida Ventas Totales hacia el campo de datos. Repite el proceso para crear tarjetas de Clientes Activos, Ventas Promedio, etc.
  • Análisis Temporal (Gráfico de líneas): Añade un gráfico de líneas. En el Eje X arrastra core_dimtiempo[nombre_mes] y en el Eje Y coloca Ventas Totales.
  • Top Productos (Gráfico de barras): Usa un gráfico de barras apiladas. En Eje Y pon core_dimproducto[nombre_producto] y en Eje X pon Ventas Totales.
  • Filtros (Segmentación): Haz clic en "Segmentación de datos" (Slicer, ícono de un embudo con una lista). Arrastra el campo core_dimtiempo[anio] o core_dimtienda[region]. Este objeto visual es clave para interactuar y filtrar todo tu reporte haciendo un solo clic.

Consejo pro: Power BI te permite crear páginas nuevas (pestañas) abajo, igual que en Excel. Usa la "Página 1" para tu Dashboard Ejecutivo y añade otra página para el Dashboard Comercial.

7. Guardar y Exportar

Finalmente, guarda tu archivo desde Archivo > Guardar como con la extensión .pbix. ¡Este es el archivo que debes entregar!
